---

# What is Local Tunnel?

- A tool to expose your local server to the internet.
- Useful for development and testing.
- Creates a secure tunnel from a public URL to your local machine.
- Examples: `ngrok`, `localtunnel`, `serveo`, `LocalXpose`
- In this lecture, we will use `LocalXpose`.

---

# Get Started with `LocalXpose`

- Install Node.js (if not already installed)
- Go to [LocalXpose website](https://localxpose.io/)
- Sign up for an account

---

# Installing `LocalXpose` CLI

- Open PowerShell as Administrator
- Set execution policy to allow script execution
  `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope LocalMachine`

---

# Installing `LocalXpose` CLI

- Install Chocolatey package manager
  - `Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))`
- Install LocalXpose
  - `choco install localxpose`

---

# Other Installation Methods

- ` npm install -g loclx`
  - Some people reported that it did not work on Windows.
- Download [binary](https://localxpose.io/dashboard/access)
  - Need to add the binary to your PATH environment variable.

---

# Login to `LocalXpose`

- `loclx account login`
  - Paste your token from the [dashboard](https://localxpose.io/dashboard/access).

---

# Start a Tunnel with `LocalXpose`

- `loclx tunnel http --to localhost:1880`
