# `Sensor Value Handler` Function Node

```js
const machine_status = flow.get("machine_status") ?? "OFF";
const sensor_value = flow.get("sensor_value") ?? 0;

  msg.payload = sensor_value;
} else {
  msg.payload = 0;
}
return msg;
```
